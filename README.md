# CI/CD Final Project

## Project Name
CI/CD Pipeline Automation with GitHub Actions, Tekton, and OpenShift

## Description
This project demonstrates a complete CI/CD pipeline using GitHub Actions,
Tekton, and OpenShift. The pipeline performs code linting, unit testing,
cleanup tasks, and application deployment.

## Technologies Used
- GitHub
- GitHub Actions
- Tekton
- OpenShift
- CI/CD
- Unit Testing
- ESLint / Linting
